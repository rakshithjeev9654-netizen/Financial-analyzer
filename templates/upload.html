📋 What data is needed?

Your file should have column headers matching these names (case-insensitive):

Balance Sheet

  • current_assets
  • current_liabilities
  • inventory / inventories
  • cash / cash_and_cash_equivalents
  • total_assets
  • total_liabilities / total_debt
  • shareholders_equity / total_equity
  • accounts_receivable
  • accounts_payable

Income Statement

  • revenue / total_revenue / sales
  • cogs / cost_of_goods_sold
  • operating_income / ebit
  • net_income / net_profit
  • interest_expense

ℹ️ Only fields present in your file are used. Any ratio that can't be computed shows as Not Available with the specific reason.
